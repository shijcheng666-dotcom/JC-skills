# 卡片模板

本文件汇集编排流程中全部记录模板。主文件说明每张卡的填写时机与决策规则，本文件只提供格式。填写时只保留当轮有内容的字段，不留空壳小节。

## 任务卡

```text
重复任务：
目标用户：
典型输入：
预期业务产物与 Skill 产物：
不可接受结果：
复用范围：
已有材料：
既有版本：
本轮需要支持的决定：
验收标准草案（必填，逐条可观察）：
  标准 1：
  标准 2：
  …
工作假设与影响（关键输入缺失时）：
```

## 路由卡

```text
本轮目标：
能力可用性：check_capability_baseline.py 输出摘要 | 缺失的专项及其限制/安装建议
标杆侦察：未触发 / 已侦察无可靠来源 / 已发现但不适用 / 已进入深度学习 / 未执行及原因
侦察结论：搜索方向、关键发现、选择或跳过依据、由此带来的限制
已选或被触发环节：Skill.环节名 | 状态（已调用 / 跳过 / 不可用）| 事实理由 | 专项产出或限制 | 交接去向
契约缺口：被调度但未定义调度接口的 Skill 及采用的最低专项产出
默认方案与假设：
```

行为改动完成后补充演进清单（见下）。

## 交接卡

本轮仅调度一个参与 Skill 的一个环节时免填；跨两个及以上环节调度时必填。

```text
已知用户要求与业务规则：
验收标准草案：（从任务卡原样复制，不得改写）
标杆来源和可复用机制：
工作假设与限制：
未决问题：
产物位置与状态：上游产物位置；已写入候选的内容；保留为候选或待验证的内容
```

## 演进清单

```text
基线版本：
备份指纹：verify_backup.py 输出的 sha256
保留项：
新增/修改项：
明确替代或退役项：（含原因、影响、验证方式）
改动理由：
改动路径回归：
未改动关键路径回归：
```

## 架构检查最小证据

```text
检查对象：
检查类型：文本审查 / Agent 实跑
脚本输出：validate_structure.py 结论（结构项）
发现项：无 / 问题描述
定位：标题、段落或行号
结论：通过 / 修正后通过 / 待验证
```

## 证据卡

```text
被测版本：
输入或场景：
成功标准：（回引验收标准草案对应条目）
实际结果：
证据位置：对话消息、运行 ID 或产物路径
结论：观察到 / 待验证 / 失败
```

创建后运行 `scripts/check_evidence_card.py` 校验；校验失败时结论只能写"已完成规则修订，尚未完成行为验证"。

## 作者决策卡

```text
当前建议：保留 / 小修后使用 / 修改后复测 / 停止投入
依据：验收标准草案各条的验证状态（逐条回引）、已核实事实、重要限制
路由摘要：引用路由卡；实际调用的环节、专项产出和未获得的关键能力收益
标杆侦察：结论、深度学习情况和未获得的能力收益
演进清单：基线版本、保留项、新增/修改项、替代/退役项及回归结果
默认方案与假设：已采用的可逆判断及其依据
下一步：一个可直接执行的动作
证据范围：真实任务 / 脱敏或合成任务 / 仅结构检查 / 仅候选方案
```
