# 分支 A 检索与筛选细则

## 团队工作区检索

列出工作区 Skills 目录（如 `.trae/skills/` 或团队约定目录）下的全部子目录，读取各 SKILL.md 的 frontmatter，按以下顺序匹配任务描述：

1. name 与任务关键词的直接匹配；
2. description 中触发场景的语义匹配；
3. 部分匹配时，阅读正文判断可改写复用的比例。

命中任一候选即记录：名称、位置、匹配点、复用方式建议（直接用 / 改写 / 仅参考结构）。团队工作区命中后不再检索外部生态，除非候选被判定不可用。

## 外部生态检索

首选 `npx skills find "<query>"`。查询词构造：用任务的核心动词+对象（如"会议纪要 整理"），先用中文；结果不足时改用英文同义词（如 "meeting minutes"）。环境无 npx 或命令失败时，降级为网页搜索（site:skills.sh 或 GitHub topic: agent-skills），并在产出中注明降级方式。

## 质量筛选优先级

1. 官方或主项目仓库发布；
2. 安装量、星标较高且近期有维护；
3. 知名组织或作者发布；
4. 其他来源：仅在无上述候选时列出，并标注来源风险。

## 产出格式

```text
候选清单（≤3）：名称 | 来源与链接 | 质量依据 | 与任务的匹配点
建议：直接采用 / 改写复用 / 自研 | 理由
审查状态：通过 / 待团队审查 / 不可确认（此时不执行安装）
或无可靠候选：已搜索范围与查询词、判断依据
```
