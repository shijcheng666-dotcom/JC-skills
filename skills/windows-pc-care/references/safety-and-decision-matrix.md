# Windows 电脑整理与提速：安全决策表

## 1. 先判断问题，而不是先“清理”

| 现象 | 先收集的证据 | 常见原因 | 优先建议 |
|---|---|---|---|
| 开机慢 | 启动项、最近安装软件、磁盘可用空间 | 启动应用过多、磁盘空间不足、更新/同步进行中 | 逐项审计启动应用；保留安全/驱动/同步关键项 |
| 打开软件卡 | 内存总量/可用量、前台进程、磁盘响应 | 内存不足、机械硬盘、浏览器标签/同步/杀毒扫描 | 在典型负载下复测；再评估 RAM 或 SSD |
| C 盘满 | 驱动器空间、临时目录体积、已安装软件、个人文件目录报告 | 缓存、软件、桌面/下载文件、云盘脱机文件 | 先清临时缓存，再由用户决定卸载/迁移具体对象 |
| 风扇响或发热 | CPU 进程、任务计划、更新状态、电池情况 | 更新、浏览器标签、同步、恶意软件或散热老化 | 找到对应程序；异常持续时查杀和硬件维护 |
| 弹窗/广告/异常进程 | 进程路径/签名、启动项、浏览器扩展 | 捆绑软件、扩展、广告软件 | 先 Defender 扫描；通过官方卸载渠道移除已确认软件 |

## 2. 风险分层

### A. 只读、可直接报告

- 硬件和系统版本、磁盘可用空间、内存使用概况。
- 已安装软件和启动项的清单。
- 临时目录的大小。
- 可见的安全状态与最近更新信息。
- 个人目录的“路径/大小/日期/类型”统计，但不读内容也不改动。

### B. 低风险但仍需确认

- 当前用户临时目录与 Windows 临时目录中的临时文件。
- Windows 设置中用户主动发起的“临时文件”清理。
- 关闭用户确认不用的普通启动应用。

确认前说明：可能跳过正在使用的文件；清理并不等于解决硬件、恶意软件或软件本身问题。

### C. 用户选择项

- 卸载明确不再使用的软件。
- 卸载可选 Windows 应用或关闭云盘功能。
- 删除浏览器扩展、迁移个人文件、清空回收站、清理下载目录。
- 修改电源模式、显示效果、存储感知设置。

必须逐项列出用途、影响、回退方式；个人文件处理必须先备份并使用回收站。

### D. 高影响项

- 关闭/禁用服务或计划任务。
- 修改注册表、磁盘分区、BitLocker、驱动、固件、BIOS。
- 禁用安全防护或更新、修改虚拟内存/休眠。
- 重置、重装或迁移系统。

只提供保守方案和备份建议；无充分证据或明确授权时不执行。

## 3. 不应默认做的事

- 删除 `C:\\Windows\\Prefetch`：Windows 用它优化启动与应用加载。
- 删除 `WinSxS`、`System32`、`pagefile.sys`、`hiberfil.sys`、驱动文件或恢复分区。
- 停用 Windows Update、Microsoft Defender、Edge 更新或系统安全服务。
- 卸载 Edge、OneDrive、Microsoft Store、厂商工具、UWP 应用。
- 结束未知系统进程、清理浏览器配置文件、读取浏览器数据。
- 直接删除软件安装目录、批量静默卸载、从不明网站下载“优化工具”。

## 4. 备份与回退

1. **个人数据**：先确认同步状态；重要项目至少保留一份独立副本。
2. **系统配置**：涉及卸载/设置变更时建议创建还原点；若还原点不可用，明确告知而非假装已保护。
3. **启动项**：记录名称、命令、位置与原始启用状态。
4. **软件**：记录名称、版本、发布者、官方重新安装来源；不保留许可证、账号或密码到报告中。
5. **变更日志**：记录时间、授权范围、操作对象、成功/失败、复检结果。

## 6. 硬件升级判断

- RAM：在用户典型工作负载下，若可用内存长期较低、程序频繁换页且系统支持扩容，再建议加内存；先核对代际、频率、插槽、最大容量和保修影响。
- SSD：机械硬盘、磁盘故障征兆或响应高才是重点；迁移系统前先验证备份与硬盘健康。
- 整机更换：CPU 平台过旧、扩容成本高、硬盘/电池/屏幕也老化时，整体更换常优于持续投入。
- 安全：SMART 警告、反复蓝屏、硬盘异响、BitLocker 恢复密钥缺失等情况优先备份与维修，而不是清理提速。
