# 用户笔录校准（User Interview Transcript Calibrator）

**版本：2.6.0**

供用户研究人员把深访、座谈会、跟访或体验研究的转录稿，校准为可直接交付和归档的 Markdown 用户笔录。

## 使用

- 需要三类材料：转录稿、用户信息表、访谈脚本。材料不齐时只核对并请求补充，不提前做全稿扫描、角色映射或关键校准。
- 流程：材料核对 → 全稿扫描 → 校准确认单（材料核对、角色映射、关键校准项、项目基准与适配决定）→ 使用者确认 → 正式整理 → 交付校验。
- 交付：默认三份独立产物——`用户笔录校准版`、`校准确认单`、`内部工作记录`；若有用户离场后的研究团队讨论，另交一份 `内部复盘记录`。
- 门禁：交付校验表逐项判定“通过／不通过／经批准例外”，任一项无法执行时不得直接标记为正式笔录。

## 2.6.0 主要变化

- 新增定位锚点规则：有可靠时间戳用原始时间戳，无时间戳用按原始段落建立的 `[段N]`，同一产物不混用。
- 新增身份置信度（高／中／低）与显示形式的降级顺序，低置信度保留原始说话人标签并登记例外白名单。
- 参与者观察改为五维度逐项结项：已提炼（标签＋事实依据＋锚点）或有依据缺省，禁止整列空白代替结项。
- 新增交付校验与门禁表（V01–V13）及 V07 计数断言，过程性内容只留在确认单或内部工作记录。
- 明确正式笔录与内部复盘的内容边界：用户离场后的团队讨论不写入正文。
