# 用户笔录校准（User Interview Transcript Calibrator）

**版本：2.5.2**

供用户研究人员把深访、座谈会、跟访或体验研究的转录稿，校准为可直接交付和归档的 Markdown 用户笔录。

## 使用

- 需要三类材料：转录稿、用户信息表、访谈脚本。材料不齐时只核对并请求补充，不提前做全稿扫描。
- 流程：材料核对 → 全稿扫描 → 校准确认单（角色映射、关键校准项）→ 使用者确认 → 生成正式笔录。
- 交付：始终一份 `用户笔录校准版`；若有用户离场后的研究团队讨论，另交一份 `内部复盘记录`。

## 数据与隐私提醒

本仓库是**公开仓库**，只存放 Skill 本身。**不要把真实访谈转录稿、用户信息表或笔录产物提交到本仓库。**
