# 版本记录

## 版本规则

- 采用语义化版本 `MAJOR.MINOR.PATCH`，版本号写入 `SKILL.md` frontmatter 的 `version` 字段，并作为 Git 标签（如 `v1.0.0`）。
- `MAJOR`：生成流程或交付契约发生不兼容变化；`MINOR`：新增能力、验收规则或参考资料；`PATCH`：缺陷修复、措辞与示例校准。
- 主分发包命名为 `graphic-report-v<版本>.zip`（含 `engine/node_modules`，开箱即有视觉检查与截图）；精简上传包命名为 `graphic-report-v<版本>-upload.zip`（不含 `node_modules`，供只接受单 Skill 的平台临时上传）。回退时按版本标签检出，不再依赖本地 zip 备份。
